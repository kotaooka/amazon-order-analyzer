# Amazon注文履歴アナライザーの解説

Amazonから受け取った注文履歴のデータ（Your Orders.zip）を読み込み、いつ・何に・いくら使ったかを集計します。読み込みと集計はブラウザの中だけで行い、データをこの端末の外に送りません。ページを閉じると、読み込んだデータは消えます。

## 注文履歴のデータを受け取る

Amazonの「[マイデータをリクエストする](https://www.amazon.co.jp/gp/help/customer/display.html?nodeId=G5NBVNN2RHXD5BUW)」から申し込みます。

1. Amazon.co.jpにログインし、「アカウントサービス」の「データを管理する」から「マイデータをリクエストする」を開きます
2. 受け取るデータに「注文履歴」（Your Orders）を選び、「リクエストを送信する」を押します
3. 届いたメールの確認リンクを押します
4. 準備ができると、ダウンロードのリンクがメールで届きます。Your Orders.zipをダウンロードします

準備には数時間〜数日かかることがあります。ZIPは展開せずに、そのままこのツールに読み込めます。

## 読み込むファイル

ZIPの中から、次のCSVを見出しで見分けて読みます。ファイル名が変わっていても読めます。請求書のPDFなど、ほかのファイルは読みません。

| ファイル | 使うところ |
|---|---|
| Order History.csv | 物品の注文。集計の中心です |
| Digital Content Orders.csv | デジタルの支払い（プライム会費、電子書籍、動画など） |
| Digital Borrowed Items.csv | Kindle Unlimited・Prime Readingの貸出 |
| Returns Status.csv | 返品と返金額 |

住所・支払い方法・追跡番号の列は、読み込んでも画面に出さず、集計にも使いません。

## 集計のしかた

### 金額

- 物品の金額は、Order History.csvの「Total Amount」です。商品ごとの支払額で、税・送料・割引を反映した値です（数量が2以上なら数量分の合計）
- Total Amountが空（Not Available）の行は、（Unit Price ＋ Unit Price Tax）× 数量で補います
- 「Order Status」がCancelledの行（キャンセルした注文）は除きます
- 通貨が複数あるときは、最も多い通貨の注文だけを足します。円とドルを足し合わせないためです
- デジタルの金額は、Digital Content Orders.csvの「Transaction Amount」の合計です。1回の支払いが本体と税の行に分かれているので、足すと支払額になります。返金はマイナスの行で入っています

### 注文数と点数

- 点数は、CSVの行の数（1行 = 1商品）です。同じ商品を2個買った行も1点と数えます
- 注文数は、「Order ID」の種類の数です。1回の注文で3商品買えば、3点・1注文です
- 1注文あたりの中央値は、注文ごとの合計の中央値です。平均ではなく中央値にしているのは、たまの高額な買い物に引っ張られないようにするためです

### 日時とタイムゾーン

CSVの日時は世界標準時（UTC、末尾の「Z」）で書かれています。日本時間ではUTCの9時間後なので、たとえばUTCの12月31日16時の注文は、日本時間では翌年の1月1日1時の注文です。年・月・時間帯・曜日は、選んだタイムゾーンに直してから数えます。

### 期間

| 期間 | 集計する注文 |
|---|---|
| 全期間 | 読み込んだすべて |
| 直近12か月 | 今の日時からさかのぼって365日 |
| 年 | 選んだタイムゾーンでのその年の1月1日〜12月31日 |

年別のグラフはいつも全期間を出します。棒を押すと、その年だけを集計します（もう一度押すと全期間に戻ります）。

### カテゴリ

Amazonの部門（Department）を、次のように日本語の分類にまとめます。

| 分類 | 部門の例 |
|---|---|
| PC・ガジェット | Personal Computers、Electronics、Wireless Phone Accessory |
| カメラ | Camera |
| 車・バイク・自転車 | Automotive、Sports |
| 衣類・服飾 | Apparel、Shoes、Watch、Luggage |
| 美容・健康 | Health and Beauty、Beauty、Drugstore |
| 食品・飲料、キッチン | Grocery、Kitchen |
| 家具・日用品 | Home、Furniture、Pet Supplies |
| 工具・DIY | Tools & Home Improvement |
| 本 | Tankobon Hardcover、Tankobon Softcover、Paperback Shinsho、Mook |
| 文具・事務、ホビー・ゲーム | Office Product、Toy、Video Game |

部門が空（Not Available）の商品は、商品名の言葉（「ケーブル」「シャンプー」「洗剤」など）で推定します。どれにも当てはまらなければ「その他」です。Electronicsのうち、商品名にカメラやイヤホンなどの言葉があるものは、カメラ・オーディオに分けます。推定なので、分類を間違えることがあります。

### リピート購入

同じ商品（ASIN）を2回以上買ったものを、回数の多い順に出します。間隔は、買った日と次に買った日の間の日数の中央値です。洗剤やサプリのように間隔がほぼ決まっているものは、定期おトク便やまとめ買いを考える目安になります。

### プライム会費

Digital Content Orders.csvの商品名が「Prime」の支払いを、プライム会費として数えます。直近12か月に2回以上払っていれば、月額プランで払っているとみなし、年間プランとの差を出します。

| プラン | 会費（税込） | 1年あたり |
|---|---|---|
| 月額 | 600円 | 7,200円 |
| 年間 | 5,900円 | 5,900円 |

会費は2026年11月時点の公表料金です。会費が変わったときは、ツールの値を直すまで差額は正しくありません。

## 使うときの注意

- Amazonの書き出したデータをそのまま足し合わせています。クレジットカードの請求額やギフト券の利用とは、締め日やポイント・ギフト券の扱いが違うので、一致しないことがあります
- 定期おトク便の割引、ポイントの還元は金額に入っていません
- Amazonビジネス・マーケットプレイスの出品者としての売上は扱いません
- CSVの見出しは、Amazonの書き出し方が変わると変わることがあります。読み込めないときは、ファイルの一覧で「使わない」になっていないか確かめてください
